# 访谈洞察报告模板

> **使用说明**
> 1. 把所有 `{{占位符}}` 替换为实际内容；无数据支撑的板块**整段删除**，不要保留空标题。
> 2. 每条结论必须附频次与原话；原话须标注 `[Sxx]` 或 `Ux`，可在 `01_segments/cleaned_text.txt` 中定位。
> 3. **小样本（单份或人数很少）时，第六节"局限性"为必填项，不得删除。**
> 4. 报告中的"原话"引自**清洗后文本**（已移除语气词），非逐字录音转写；如需逐字引用，须回 `00_raw/` 取原文并在引用处注明。
