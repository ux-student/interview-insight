# 三级编码框架（扎根理论方法，用研适配版）

本文件是访谈分析的专业内核。对访谈文本做结构化洞察时，严格按「开放编码 → 轴心编码 → 选择编码」三级执行，确保输出是可溯源的研究结论，而非文本摘要。

## 目录
1. 一级：开放编码
2. 二级：轴心编码（5大核心范畴）
3. 三级：选择编码

## 1. 一级：开放编码（Open Coding）

逐句扫描清洗后的文本，为每一个有效表达打标签。

**规则：**
- 只描述、不推断：标签贴近用户原生语义，禁止提前下结论
- 用短语（名词/动词），不用完整句子
- 一个表达可打多个标签；同一语义在不同段落重复出现时复用同一标签（用于累计频次）
- 同时记录情绪强度线索（如"特别疼""完全没法用"），供三级编码判断影响程度

**通用标签池（可按产品增补）：**
用户属性｜使用场景｜触发时机｜功能评价｜操作行为｜体验痛点｜物理感受｜使用动机｜替代方案｜未满足需求｜改进建议

**反例（禁止）：**
- 用户说"戴半小时耳朵根就疼" → 标签写"产品设计不合理"（这是推断，不是开放编码）
- 正确标签：`佩戴30min耳根部疼痛`

## 2. 二级：轴心编码（Axial Coding）

将开放编码标签按语义关联聚类为主题范畴，并梳理范畴间关系（因果、场景触发、先后顺序）。

**5大核心范畴（覆盖约90%人因/用研场景，可按研究目标增删）：**

| 范畴 | 收录内容 | 典型标签 |
|---|---|---|
| C1 用户与场景 | 人群特征、使用环境、触发时机、任务目标 | 通勤场景、运动场景、新手用户、睡前使用 |
| C2 功能体验 | 功能满足度、功能缺失、性能表现、可靠性 | 续航不足、连接不稳、功能找不到、漏音 |
| C3 交互体验 | 操作流程、学习成本、反馈、信息呈现 | 操作步骤多、无提示、误触、看不懂图标 |
| C4 物理体验（人因） | 佩戴/握持/触感/重量/压迫/疲劳/声光刺激 | 夹持过紧、耳根部压痛、重量感、长时间疲劳 |
| C5 态度与期望 | 满意度、对比评价、容忍度、改进建议、潜在需求 | 希望可调节、愿为此付费、凑合能用 |

**关系梳理：** 用"条件 → 行动 → 结果"语句连接标签，例如：
`运动场景（条件）→ 出汗后耳机滑动（行动/现象）→ 需要频繁推回、注意力被打断（结果）`

## 3. 三级：选择编码（Selective Coding）

围绕研究目标，从范畴中提炼核心洞察并输出业务启示。

**每条洞察必须包含四要素，缺一不可：**
1. **结论**：一句话陈述发现
2. **频次/覆盖**：多少名受访者、多少个段落提及（多份访谈时给人数，单份给段落数）
3. **原话佐证**：至少1条用户原话（引用，可截取，标注段落编号 [S03]）
4. **业务启示**：对产品/设计的含义或建议方向

**核心故事线：** 用一条主线串起核心范畴，例如"物理佩戴问题在运动场景下被放大，进而影响整体满意度与复购意愿"。

**禁止事项：**
- 无原话支撑的主观判断
- 把单个用户的极端表述包装成普遍结论（须标注"个案"）
- 输出"未来可进一步研究"式学术收尾——必须落到可执行建议

## 4. 频次与优先级统计规则

- **提及频次**：同一标签在同一段落内重复出现只计1次；跨段落/跨用户分别累计
- **痛点优先级矩阵**：按 `影响程度 × 出现频次` 排序
  - 影响程度判定：是否阻断核心任务、是否涉及安全/健康、情绪强度、是否引发弃用/差评/退货
  - P0（高频×高影响）：立即处理；P1（高频×低影响 或 低频×高影响）：排期处理；P2（低频×低影响）：观察
- 多人访谈时同时报告"提及人数/总人数"，避免单份访谈权重失真

## 5. 完整编码示例

**原始文本（[S03]）：**
"我跑步戴这个耳机，差不多二十分钟吧，耳朵后面这块就开始夹得疼，出汗之后还会往下滑，总得用手去扶，挺烦的，后来跑步我就换回旧耳机了。"

**开放编码标签：**
`跑步场景` `佩戴20min耳后疼痛` `夹持致痛` `出汗后下滑` `需手动扶正` `烦躁情绪` `运动场景弃用` `换回竞品`

**轴心编码：**
- C1 用户与场景：`跑步场景`
- C4 物理体验：`佩戴20min耳后疼痛` `夹持致痛` `出汗后下滑`
- C2 功能体验：（运动稳定性不足）`出汗后下滑`
- C5 态度与期望：`烦躁情绪` `运动场景弃用` `换回竞品`
- 关系链：跑步+出汗（条件）→ 夹持疼痛+下滑（现象）→ 手动扶正、烦躁（结果）→ 场景弃用、换回竞品（后果）

**选择编码（洞察）：**
> **结论：** 耳挂夹持力与运动稳定性不足，会直接导致运动用户在场景内弃用。
> **频次：** 单份访谈中于[S03]集中出现（多人访谈时替换为"X/Y名用户提及"）。
> **原话：** "二十分钟吧，耳朵后面这块就开始夹得疼，出汗之后还会往下滑……后来跑步我就换回旧耳机了。"[S03]
> **业务启示：** 夹持力与防滑设计是运动场景的P0人因项，建议优先验证耳挂弧度与接触面材质，并在运动场景下做佩戴稳定性测试。
